## Summary

### M-14
`kill_group` previously only sent `SIGKILL` to the process group (−pgid). A descendant that called `setsid(2)` created a new session and group, surviving as an orphan. Now `kill_descendants` enumerates all PIDs via `proc_listallpids` (macOS `libproc`), queries each for parent PID via `proc_pidinfo(PROC_PIDTBSDINFO)`, and BFS-kills every descendant of the leader. Non-macOS unices get a no-op stub.

### M-15
`build_seatbelt_profile` interpolated paths directly into the S-expression string via `format!`. A path containing `\`, `"`, `)`, `\n`, or NUL could alter or truncate the policy. The new `seatbelt_escape_path()` escapes `\`→`\\` and `"`→`\"`, and returns `ExecError::SandboxApply` on control characters or non-UTF-8 (fail-closed). `build_seatbelt_profile` now returns `Result`.

### L-05
The `tokio::select!` in `run_guarded` had an early `return Err(...)` on `child.wait()` failure, which skipped joining the drain tasks and deleting the temporary Seatbelt profile. Now the error is collected into `wait_err: Option<String>`, the process group is killed, drain tasks are joined, and profiles are deleted — then the error is returned.

## Follow-ups

- Non-macOS unices need a tree-walk implementation (Linux: `/proc` or `PID cgroup`)
- The `proc_listallpids` buffer is hardcoded at 4096 — use `sysctl` or iterative doubling for large systems
- No process-resource limits (CPU/filesize/nproc) are applied — these would constrain a runaway even if it escapes the tree walk
