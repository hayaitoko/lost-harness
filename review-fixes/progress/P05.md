## Findings

### H-06 — URL validation (ipc/mod.rs + client.rs)

Added `validate_base_url()` function that rejects:
- Unparsable URLs, embedded credentials (`user:pass@`), fragments (`#`), empty hosts
- Non-HTTPS for non-loopback (explicitly gates HTTP for `localhost`/`127.x.x.x`)

Called in both `add_provider` and `update_provider` before any state mutation. In `client.rs`, `ModelClient::new` now sets `redirect(reqwest::redirect::Policy::none())`.

### M-05 — Atomic provider mutations (ipc/mod.rs)

- `add_provider`: keychain → DB insert (error propagated) → in-memory add
- `update_provider`: snapshots old secret, persists DB before memory, restores old secret on failure
- `remove_provider`: reordered to DB delete → keychain delete → memory remove

### M-12 — remove_local_model file ordering (ipc/mod.rs)

File deleted first (with `?` propagation). DB row kept on file-delete failure. No more orphaned GGUF files.

### M-22 — No fabricated routing (ipc/mod.rs)

`send_message` fallback changed from `(Uuid::new_v4(), "allow")` to `("", "unknown")`.

### L-01 — Real version (ipc/mod.rs)

`get_app_version()` returns `env!("CARGO_PKG_VERSION")` (`"0.1.0"`) instead of hardcoded `"0.1.0-m1"`. Test updated.

### M-01 — Bounded bodies (client.rs / sse.rs)

**client.rs:** Added `capped_error_body()` (4 KiB) and `capped_json_body()` (10 MiB). Applied to all 3 error paths and 2 JSON success paths.

**sse.rs:** Added `MAX_LINE_LENGTH` (16 KiB), `MAX_BUFFER_SIZE` (512 KiB). Enforced on buffer push and line extraction.

### New contracts

- `set_provider_api_key(provider_id, api_key)` — one-shot key rotation (for P04)
- `PACK_IMPORT_MAX_BYTES = 1_000_000` — enforced in `install_pack` before `parse_pack` (for P13)
